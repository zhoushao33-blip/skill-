# 谢老英语｜课程内容与作业清单图片 Skill

此仓库存放“课程内容 + 作业清单”家长群通知图片的可复用生成 Skill。

## 入口

- [Skill 指令](skills/xielao-lesson-homework-poster/SKILL.md)
- [固定视觉规范](skills/xielao-lesson-homework-poster/references/design-spec.md)
- [初三秋季第 7 讲示例](skills/xielao-lesson-homework-poster/examples/grade9-autumn-lesson7.md)

## 使用方法

将本 Skill 的 SKILL.md 和 references/design-spec.md 提供给支持图片生成的 AI 助手，随后输入：

“按谢老英语固定模板，制作初二秋季第 X 讲的授课内容与作业清单图：……（粘贴完整原始文字）”

如要修改上一张图片，只输入需要更改的内容，例如：“只把第 3 项作业改成 1 次指定 + 4 次自选，其余全部不变。”

## 模板原则

- 竖版家长群图片；上下分区，上授课、下作业。
- 授课内容次要，尽量用 2×2 左右双栏；作业清单重点突出、占较大面积。
- 海军蓝、灰蓝、暖白、砖红，清爽稳重，无旁侧卡通插画。
- **数字、页码、次数、教材名称、指定/自选要求以用户最新文字为准，不得猜测和擅改。**
- 图像生成后检查所有中文是否准确，发现错误要修正；不要把含错字图片当作最终版。

**注意：** 仓库是 GitHub 公开仓库；不要向示例中添加学生姓名、私人聊天、联系方式或其他个人信息。
