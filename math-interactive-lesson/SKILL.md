# Math Interactive Lesson / 数学题互动 HTML 课件

## 核心承诺

把**用户上传的数学题照片或文字**制作成可直接下载并**双击打开的单文件 HTML**。教学顺序必须是“读题 → 解题思路 → 方法选择 → 逐步计算 → 动态验证 → 回顾与防漏解”。由学生/老师主动按下一步，不能自动播完。原则：**数学正确性优先于好看的动画，能够打开和操作优先于动画复杂度。**

## 输入与触发

- 上传题目图、要求“下一题/做成 PPT 一样的互动网页/做成 HTML”时，先确认实际题干、图形、子问题和已有范围，不要误用前一题。
- 同一道题多张照片，要依据题号和图形匹配。拍歪的图片先转正检查，遮挡、裁切和红笔批注要区分。
- 默认输出中文、初二教学语言、桌面 16:9 友好且手机自适应、大字、无背景音乐、无网络依赖；**不要求用户重复已给条件**。
- 如果用户只要求某一小问，严格只制作该小问和必要前置知识；不要擅自加全部解答。

## 工作流程（按顺序执行）

### 1. 读图和复核题意

1. 逐字整理题干和子问题，特别确认根号范围、分式分母、指数、角标、符号、坐标、范围、等号与不等号。
2. 把“确定的题意”和“照片不清楚的地方”分开记录。关键信息无法识别时，不要假设出正确答案；可先处理可辨认部分。
3. 不把学生/老师手写批注自动当作题目条件。对照题号、防止串题。

### 2. 独立解题并验证

1. 先给出知识路线图，不直接堆公式。优先提供适合初中学生的解法。
2. 所有答案必须独立复算；可用 Python/SymPy 做符号或数值校验，**不能只依靠某个截图上标注的答案**。
3. 必查：定义域、取值范围、根号非负、分母非零、几何非退化、正反向与绝对值、全部分类、两端点是否可取、单位。
4. 线段/三角形动点题：用坐标或长度式校验每个候选点。等腰三角形要分三种边相等；直角三角形根据题意分直角顶点。
5. 除非有明确约束，不能把线上的动点只限制在图中看见的那一小段。
6. 如发现先前答案存在错误，必须先纠正，再生成网页；不要沿用错误例题。

### 3. 把解法拆成“点击一步”

每步有五个信息：**标题、先想什么、当前新增推导、图形状态、方法提醒**。一个点击只增加一条重要推导，不把整页答案一次显示。

推荐章节：读懂题目（1–2步）→ 整体思路（1步）→ 各小问的推导（各3–8步）→ 动手实验（1–2步）→ 最终答案和类似题方法。复杂题允许 12–30 步，按题意而非固定数量。

### 4. 开发离线 HTML

- 先看 `templates/lesson_starter.html`，需要快速建页时运行 `python scripts/new_lesson.py --title '题名' --out index.html`。
- 真实课件应针对题目定制 `<svg viewBox>` 中的图形和数据逻辑；参考 `examples/` 里函数、几何和动点的成品，不要照抄上一题的数据。
- 一个 `index.html` 内联全部 HTML/CSS/JS；**不得依赖 CDN、远程字体、外部 MathJax/GSAP 或网络图片**。数学式优先用清晰 Unicode、HTML 或原生 SVG；复杂式必要时由离线程序生成 SVG 并内联。
- 默认显示第 1 步，加载后可直接点击；`prev`、`next`、章节跳转、重头开始都要生效。键盘方向键可作辅助操作，但不能替代可见按钮。
- 动点参数变化必须联动图形、坐标、边长、面积、检验消息。滑块应有明确范围、步长、坐标单位和数值读数。
- 用 `viewBox` 做自适应布局，保持数字和点位标签可读；**不能因 viewport 改变而遮住图形/裁掉坐标轴**。
- 明确标出“这是试验值/近似值”与“这是准确解”，必要时使用分数/根号的精确形式。
- 禁止全页自动播放和无关动画；适配 `prefers-reduced-motion`。

### 5. 验收与交付

1. 对单文件执行：`python scripts/check_lesson.py path/to/index.html`（含 HTML/CSS/JS 的静态检查）。
2. 若装有 Playwright/Chromium，执行：`python scripts/browser_smoke.py path/to/index.html`。检查初始显示、下一步/上一步、章节跳转、滑块变化、控制台错误、手机横向溢出。
3. 对各小问末尾页面和滑块边界拍图检查：文字不压线、公式不截断、交互按钮可点击、坐标与数值一致。
4. 尝试本地 `file://` 加载，而不仅在服务端 HTTP 预览。无法进行某项测试时如实披露，不能称“已经验证”。
5. 交付**单文件 `index.html`**，并提供**独立 ZIP**（包含 HTML、README）；遇到下载失败，优先核查真实文件存在，不要编造链接或原地无限重发。

## 避免的常见失败

- HTML 首屏空白：不要把时间线默认暂停后不提供播放方式。
- 图看着对、数学却错：互动验证公式必须与答案同一套定义。
- 滑块只改文本、不改图：所有依赖由同一状态变量更新。
- 出现“有两个解”却只画一个；误将图中动点示意范围当作严格条件。
- “截图验证通过”但没有实际浏览器运行：必须区分静态检查与真实运行。
- 认为浏览器可以联网：不要用第三方 CDN。
