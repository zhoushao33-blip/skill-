# 教学拆解与数学核验

## 教学顺序

读懂题目 → 提取条件 → 先想什么 → 选知识点 → 一次一个关键推导 → 辅助线/动态图 → 答案验证 → 防漏解 → 方法总结。

## 选择交互

- 一次函数：SVG 坐标图，动点沿直线移动并同步更新坐标、斜率、面积。
- 等腰三角形：三种边相等情况分别推导，排除退化三角形。
- 等腰直角：分类讨论直角位置，检查直角与等腰两条件。
- 面积：高亮底和高；动点滑块驱动面积实时更新。
- 根式裂项：有理化与抵消逐步可视化，严禁把近似值写成精确相等。
- 最值应用：面积/成本范围、目标函数、单调性、端点检验。
- 坐标周期：明确序号从 P₁ 还是 P₀ 开始，并用多项计算验证周期。

## 质量审查

解法应适合初中学生；数学必须独立复算；分母不能为 0、根号必须有意义；所有解需要在公式和图上同时显示。图片中的点位仅为示意，条件以题干为准。
