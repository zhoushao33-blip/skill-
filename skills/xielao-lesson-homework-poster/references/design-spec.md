# 固定视觉规范｜方案 A

## 设计定位

面向“谢老英语”学生家长群的竖版“课程内容 + 作业清单”通知海报。**稳重、清爽、信息效率高、没有旁侧图片**。视觉模板由用户反复选择和确认，生成时不随意变换排版。

## 版心与层级

- 推荐画布：1024 × 1536 像素（2:3 竖版）。安全边距约 24–36 像素。
- 上方约 10%：深海军蓝圆角标题栏。左边“初三秋季第7讲”等主标题，右边“学习安排 / GRADE 9”。
- 中间约 29–32%：浅灰蓝授课内容区。小标题“本讲授课内容 / CLASS CONTENT”，内容为 2 列 × 2 行。只有 3 项时，采用两栏首行 + 横跨第二行或视觉上均衡的三项布局。课程部分是次要信息。
- 下方约 52–57%：暖白作业清单区。砖红“第7讲 作业清单 / HOMEWORK”大标题，下面按 1、2、3、4 顺序纵向排。作业信息的可读字号要大于或等于授课说明。可因文字长度灵活增减高度。
- 尾部保留 2–3% 呼吸空间；不可裁切正文。

## 配色（A 方案）

| 用途 | 色号 | 说明 |
| --- | --- | --- |
| 顶部横幅/主正文 | #183153 | 深海军蓝，稳重专业 |
| 授课区标题/次级标注 | #7188A1 | 灰蓝色，低对比 |
| 授课区底色 | #F1F5F8 | 极浅灰蓝 |
| 作业区底色 | #FAF5EC | 暖白/浅米色 |
| 作业区标题与数字强调 | #B65B50 | 低饱和砖红 |
| 普通文字 | #172C48 | 深蓝黑，清晰 |
| 分隔线 | #DDCDC4 | 淡暖灰 |

色号是参考目标；实际生成时允许轻微变化，必须保持低饱和、文字对比足够。不要使用荧光粉、亮黄、鲜红或大面积渐变。

## 排版细节

- 现代无衬线中文字体，黑体/思源黑体类风格；标题粗体、内容适中。
- 顶栏的讲次数“7”可用米白突出；数字与标题字体一体化，不添加光效。
- 授课区编号用浅灰蓝圆圈，文字排列宽松，用细线划分 2×2。
- 作业区编号用砖红色圆圈；每项以细分割线隔开；重点页码、次数、分钟数才用砖红加粗。
- 课程区不需过多解释；作业区优先完整文字，长句换行而不缩得太小。
- 适当保留“基础弱的同学……”等温和提醒，但不擅自添加劝学鸡汤。
- 不使用人像、书本插图、卡通人物、手绘便签、彩色气泡图，图形元素限于圆角块、圆形序号和细线。

## 图片生成时的专用视觉提示

按照“谢老英语固定课程通知模板 A”创作一张中文竖版信息图：顶部深海军蓝横幅，标题“{年级}秋季第{讲次}讲”，右侧学习安排/年级标记；上方浅灰蓝“本讲授课内容”，条目按左右双栏 2×2 排列，弱化处理；下方暖白“第{讲次}讲 作业清单”，砖红标题条、醒目序号，条目纵向列表，文字深海军蓝，教材页码、打卡次数、时长用砖红强调。排版整齐，专业沉稳，留白充足，无任何旁侧图片和卡通装饰。准确排入用户提供的全部中文文案；不能新增、删除、修改数字或文字。
