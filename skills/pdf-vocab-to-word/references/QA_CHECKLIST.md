# QA：每次 Word 出题前后核对

## 输入
- [ ] 已确认正确年级及同一版本的重词书 PDF
- [ ] 用户要求的是 Pxx-Pyy 物理页码（含两端）
- [ ] 已找到相同年级的 .docx 模板，未误用其他年级 Word
- [ ] 每一页高分辨率图像都已检查，不只看抽出的文本

## 标记对账
- [ ] 主词条编号→中文
- [ ] 星号→中文
- [ ] 半勾→英文
- [ ] 同一编号主词条与派生词分别判断
- [ ] 大括号/整组标记全部覆盖
- [ ] 跨页续接未遗漏，重复标记按源书保留
- [ ] 练习题的序号、勾、叉、圈未误收录
- [ ] 所有 PDF 页都记录了数目，零条页面亦有说明
- [ ] 英文单复数、大小写、连字符、介词、标点已复核
- [ ] 统计数量 = entries.json 实际条数

## 格式与交付
- [ ] 复制原模板数据行 XML 而不是重建表格
- [ ] 标题字体与段落样式未变，原有页面设置未变
- [ ] 字体、字号、边框、列宽与示例行一致
- [ ] 逐页渲染输出，检查长词条、断行、跨页和空白页
- [ ] Word 文件存在且能重新打开，ZIP 能解压
- [ ] Word/ZIP 英文文件名，链接指向本次确切存在的路径
- [ ] 未宣称通过程序可读验证就等于客户端下载成功

## 同步
- [ ] 修改经用户明确确认
- [ ] 获取 GitHub 最新版本后提交差异
- [ ] 记录提交 SHA 和文件地址
- [ ] 若定时任务无法获取新变更来源，不要虚构更新
