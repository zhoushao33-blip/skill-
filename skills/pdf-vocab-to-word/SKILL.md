# 重词书 PDF → Word 课前复习小测

## 触发场景
用户说“找到七/八/九年级上学期重词书”“整理第 Pxx–Pyy 页到 Word”“数字和星星中文、半勾英文”“原 Word 字体、格式不能变”时使用。
本 Skill 不做学生小测批改。范围指 **PDF 物理页面**，包含起止页，不是词条序号。

## 收录规则（不可自行调整）
1. 原书主词条**数字编号** → 输出中文释义（保留常用多义）。
2. 词条前手写**五角星/星号** → 输出中文释义。
3. 词条前手写**半勾/钩形符号** → 输出英文原词、词组或固定搭配。
4. 同一个主词条既有印刷编号又出现其他手写标记，主词条以“编号→中文”为准；其下单独标记的派生词/搭配各自判断。
5. 如果半勾/星号标记的是一组，逐项收录整个被标注范围，不能只抄第一项；对不确定的范围放大复核。
6. 不把练习题 1)、2)、选择题选项里的数字当作主词条号；不把教师打的解题勾、叉、圈当作词条标记。
7. 同一内容在源 PDF 中重复出现且均有标记，保留重复，不擅自去重。
8. 不自行加入没有符合标记的词条。跨页续接的带标记搭配应收录。
9. PDF 文字提取不能可靠反映手写标记，必须查看指定页的原始图像。

## 查找文件和选用模板
- 找到用户指定年级的原始重词书 PDF（尽量是之前确认的同一版本）。
- 找到 **同年级的 .docx 原版小测模板或之前成功生成的 .docx**；七年级不得套八年级或九年级，反之亦然。
- 用户附带其他年级 Word 时，不要误选；优先寻找正确年级的 Word。
- 若只有 PDF、没有同年级 Word 模板，明确说明无法保证 100% 原样式，不能用新建近似格式冒充。
- 必须保留原有：页尺寸、页边距、字体族、字号、加粗、段落间距、行距、表格列宽/边框、页眉页脚、标题格式、答题列结构。条目增加会改变页数，因此所谓“格式保持原样”是样式参数，不是字节级/像素级完全相同。

## 执行步骤
1. 明确用户给定的年级、源 PDF 和物理页码区间（含起止页）；确认文件总页数和印刷页码的区别。
2. 用 PyMuPDF 或同等 PDF 工具将 Pxx—Pyy 按 160–220 DPI 渲染为 PNG，并逐页放大读取。
3. 针对每一页建立核对记录：页码、数字→中文数量、星→中文数量、半勾→英文数量、本页最后词条、是否无合格标记。
4. 构建 entries.json：每项记录 page、mark（number/star/half_check）、source（源词条）、text（目标填写词条）；须与 PDF 阅读顺序一致。若有无法识别的手写符号，记录不确定项并复核，不要猜。
5. 主词条中文释义尽量沿用书上的释义；半勾英文须核对大小写、单复数、词组空格、介词和连接符。
6. 用原版 Word：复制模板中已存在的数据行的 XML 和原有段落/run 样式，只填左侧第一列并清空答题列；不要新建表格、改字体、改字号、改列宽、改全局样式。
7. 标题修改仅替换原有 run 的文字，不改标题样式。必要的长词条自动换行或人工插入换行不能造成文字出框或表格错位。
8. 输出 ASCII 英文文件名：Grade7_P45-54_Words.docx、Grade7_P45-54_Words.zip（其他年级和区间类推）；ZIP 至少包含 Word。
9. 逐页对账源 PDF：每页都经过检查，整组标记不遗漏，练习题批改勾不误收录，首尾页覆盖到位。
10. 渲染输出 Word 的全部页面，检查文字重叠、断词、靠边框、额外空白页、分页；长英文必要时只调整文字换行，不调字体、列宽或页边距。
11. 验证 .docx 在当前运行环境存在、可以重新解析，ZIP 可读取且内容一致；**仅能确认本地/环境文件完整，不能保证用户客户端一定下载成功**。
12. 最后准确汇报 PDF 页码范围、数字/星/半勾条数、总数、实际检查的 Word 页数，以及 Word 和 ZIP 的可用链接；未验证的数值不可编造。

## 推荐命令
安装依赖：python-docx、PyMuPDF。
先运行 scripts/render_pages.py 渲染目标 PDF 页面，人工确认后再按 examples/entries.example.json 编辑清单。
使用 scripts/build_word.py 将清单填入原版 Word。脚本本身不承担手写标记视觉识别。
