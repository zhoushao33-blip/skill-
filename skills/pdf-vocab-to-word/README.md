# 重词书标记整理到 Word（PDF Vocabulary to Word）

触发：指定七/八/九年级 PDF 重词书的 Pxx-Pyy 物理页，依标记生成原版式的 Word 课前小测。

- 数字编号 → 中文
- 五角星 → 中文
- 半勾 → 英文
- 原书的练习题批改记号不算词条标记
- 必须逐页对账，整组标记逐项记录
- 以正确年级的原 Word 为模板，保留字体/字号/表格等既有格式
- 优先生成 ASCII 英文文件名的 .docx 和 ZIP，检查文件完整性
